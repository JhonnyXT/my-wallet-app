Registro por voz

Di "McDonald's 25 mil ayer" y MyWallet transcribe, interpreta y registra el gasto por ti — la voz nunca se graba ni se almacena.

Detección bancaria automática

Lee las notificaciones de tus apps bancarias (Bancolombia, Nequi, Davivienda, Nu y más) y te propone la transacción para que la confirmes con un toque.

Categorías dinámicas

📊

Gráfica de categorías

Visualiza en qué se te va el dinero con una gráfica de barras interactiva — toca una columna para filtrar tus transacciones al instante.

🎯

Privacidad primero

Tus datos financieros nunca salen de tu teléfono

MyWallet no tiene backend. No hay cuenta, no hay login, no hay servidor que pueda filtrar tu información — porque simplemente no existe.

  • ✓ Base de datos SQLite local, excluida del auto-backup de Android
  • ✓ Detección bancaria: solo monto y comercio, nunca saldos ni números de tarjeta
  • ✓ El audio de voz se procesa en tiempo real y no se guarda
  • ✓ Código abierto — puedes revisar exactamente qué hace
